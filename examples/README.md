# Examples

| File | What it shows |
| --- | --- |
| [quickstart.py](quickstart.py) | A two-node exodus network in one process: identities, claims, consensus, and credits. Run it with `python examples/quickstart.py`. |
| [exo_hooks.py](exo_hooks.py) | The intended seams for wiring exodus into the exo runtime (API mount, worker hook, priority mapping, zenoh bridge). Snippets are documentation, not runnable as-is — the exo API varies by version. |
